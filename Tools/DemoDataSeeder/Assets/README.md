# Fotos de demonstração

Estas seis imagens são retratos sintéticos, gerados para os perfis fictícios do AgendaiFisio.
Nenhuma delas representa uma pessoa real cadastrada no aplicativo.

Todas foram geradas com o modo integrado de geração de imagens, em fotografia editorial
realista, enquadramento quadrado de cabeça e ombros, clínica de fisioterapia desfocada,
luz natural e margem suficiente para o recorte circular. Os prompts solicitaram adultos
brasileiros fictícios diversos, usando roupa profissional sem logotipos, textos, marcas
d'água, símbolos médicos ou estetoscópio.
